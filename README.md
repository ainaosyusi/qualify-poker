# Qualify Poker (役判定練習)

ポーカー（テキサスホールデム）の役判定や勝者判定を素早く、正確に行うための練習ツールです。
通常のテキサスホールデムに加え、ミックスゲーム（スーパーホールデム、オーシャン）のルールにも対応しています。

## 特徴

- **2つのゲームモード**:
  - **通常モード**: 標準的なテキサスホールデムの練習。
  - **ミックスゲーム**: 特殊なルール（スーパーホールデム、オーシャン）の練習。
- **多彩なサブモード**:
  - **役を選ぶモード**: 指定されたハンドの役を回答します。
  - **勝者を選ぶモード**: 複数のプレイヤーの中から勝者を判定します。
  - **タイムアタック**: 20問の正解までの時間を競い、スコアとランクを表示します。
- **便利機能**:
  - **色アシスト**: 4色のスート表示で視認性を向上させます。
  - **振り返り機能**: タイムアタックで間違えた問題を後で確認できます。

## 使い方

1. `index.html` をブラウザで開きます。
2. 練習したいモード（通常 or ミックスゲーム）を選択します。
3. サブモード（役、勝者、タイムアタック）を選択します。
4. プレイヤー人数を設定し「開始」ボタンを押します。
